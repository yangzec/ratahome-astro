# 设计系统 -- Trade Site Platform

项目级设计规范。所有站点（含 `ratahome-furniture`、`chromora-yarns` 及后续行业站）以本文为**可执行标准**；`theme.json`、站点 CSS 与 Blueprint 不得与本文冲突。

操作手册见 `docs/USAGE.md`。进度见 `ROADMAP.md`。

---

## 1. 总则

- **先删后加**：新增区块、颜色、字号或装饰前，先证明现有项无法承担同一职责。重复叙事、重复强调色、重复字族一律删除。
- **每屏 / 每区块一个焦点**：Hero 焦点是主标题 + 主 CTA；产品区焦点是品类；信任区焦点是数字或证书；不要在同一视口并排抢注意力。
- **大面积用中性色，彩色只做强调**：色块不是装饰层。
- **站点差异用 token 与内容，不 fork 组件**：共享 Section 保持家具站可用；行业站用 `theme.json` + 站点 CSS 覆盖，禁止为换色改 `packages/sections`。

---

## 2. 配色

### 2.1 硬性规则

- 有彩色角色 **不超过 3 个**。推荐只保留 **1 个** 强调色（Accent），其余为中性。
- 面积遵循 **60-30-10**：
  - **60%** 表面：浅中性（cream / white）
  - **30%** 结构：深中性（ink / charcoal / 深色条带）
  - **10%** 强调：唯一有彩色，只用于 CTA、链接、eyebrow、焦点图标描边
- 大面积背景只用 60% 中性或 30% 深色条带。禁止用强调色铺 Hero、页脚或整屏卡片底。
- 禁止第二套「装饰色」（暖橙、品红、第二青绿）与强调色并存。
- 站点 `theme.json` 覆盖后，该站 CSS **不得**再写家具默认色作为可见回退。

### 2.2 Chromora Yarns 三色实例（canonical）

| 角色 | 面积 | Token | 值 | 用途 |
|------|------|-------|-----|------|
| Surface | 60% | `cream` / white | `#F4F5F3` = `244 245 243` / `#FFFFFF` | 页面底、浅色区块、卡片底 |
| Ink | 30% | `ink` / `oliveDark` | `#1C2224` = `28 34 36`；深条 `18 28 30` | 标题、正文、顶栏、页脚 |
| Accent | 10% | `accent` | `rgb(14 92 99)` = `14 92 99` | 主 CTA、链接、eyebrow |

`creamDeep`（`230 233 230`）是 60% 表面的相邻阶，用于 hover / 次级浅底，**不是**第四有彩色。

### 2.3 Token 映射（schema 兼容）

`packages/site-cli` 仍校验家具站留下的 12 个颜色键。Chromora **不删除键名**（删除会让 `pnpm site-cli validate` 失败），但全部映射进三色 + 必要中性，禁止再表达家具暖橙或暖奶油：

| `theme.json` 键 | Chromora 角色 | Chromora RGB | 家具站对照（勿用于 Chromora） |
|-----------------|---------------|--------------|------------------------------|
| `accent` | 10% 强调青绿 | `14 92 99` | `192 92 21`（`#C05C15`，**禁用**） |
| `cream` | 60% 表面 | `244 245 243` | `252 247 243`（暖奶油，**禁用**） |
| `creamDeep` | 60% 表面深一阶 | `230 233 230` | `249 241 229`（暖奶油深，**禁用**） |
| `ink` | 30% 正文 / 标题 | `28 34 36` | `43 44 39` |
| `charcoal` | 30% 更深字 | `20 24 26` | `26 26 26` |
| `olive` | 30% 中深条 | `48 62 60` | `79 83 69` |
| `oliveDark` | 30% 顶栏 / 页脚 | `18 28 30` | `30 32 21` |
| `chrome` | 30% 近黑 | `16 22 24` | `27 28 23` |
| `grayText` | 中性正文 | `62 68 70` | `69 69 69` |
| `grayMuted` | 中性辅助 | `108 114 116` | `125 125 125` |
| `stone` | 中性弱装饰 | `172 178 174` | `194 195 189` |
| `border` | 中性线 | `210 214 210` | `221 221 221` |

新增站点：先定三色，再填这 12 键；不要发明 `gold` / `blush` / `highlight2`。

### 2.4 禁用清单

- Chromora 与后续非家具站：**禁止** `#C05C15` / `rgb(192 92 21)` 作为 accent 或图标填充。
- Chromora：**禁止** 暖奶油 `rgb(252 247 243)`、`rgb(249 241 229)` 作为 `@theme` 默认值。
- 共享 CSS 可以保留家具默认，供 `ratahome-furniture` 使用；**站点级** `sites/{slug}/src/styles/global.css` 的 `@theme` 必须与该站 `theme.json` 一致，避免注入失败时回退到家具橙。

## 3. 字体

### 3.1 硬性规则

- 每站 **不超过 2 个字族**。能 1 个解决就不要 2 个。
- **层级只用字号与字重**，不用第二字族充当「标题字体」。
- 字号阶梯 **3--4 级**，禁止 `13px` / `15px` / `17px` 以及 `text-[15px]` / `text-[16px]` 这种一次性取值。
- 行宽：中文正文 **25--40 字**；英文正文 **45--75 字符**。正文必须设 `max-width`（`ch` / `em` 或已度量的容器），禁止通栏长文。
- 字重常用 `400` / `500` / `600`；`700` 仅用于 eyebrow 或极短标签。

### 3.2 推荐阶梯（4 级）

| 级 | 角色 | 字号 | 字重 |
|----|------|------|------|
| 1 | Label / eyebrow | `0.75rem`（12px） | 600--700 |
| 2 | Body / 导航 | `1rem`（16px） | 400--500 |
| 3 | Title（h2 / h3） | `1.5rem`--`2rem`（24--32px） | 600 |
| 4 | Display（h1） | `clamp(2rem, 5vw, 3rem)`（32--48px） | 600 |

辅助说明可用 Body 的 `0.875rem`（14px）**仅当**它不成为第五级标题。不要同时出现 12 / 13 / 14 / 15 / 16。

### 3.3 Chromora 字体

- **唯一字族**：Inter（`sans` / `label` / `display` 三键都指向 Inter）。
- **禁止** Cinzel、Poppins 出现在 Chromora 的 CSS 变量、`@import` 或计算后的 `font-family`。
- 家具站可以继续使用 Cinzel + Poppins + Inter；不要把家具 `@theme` 字体复制进 Chromora。

## 4. 布局

### 4.1 硬性规则

- **对齐网格**：区块左右对齐 `container-site`；卡片、数字、步骤同一基线，不自由漂。
- **接近原则**：标题与其说明、标签与其控件的间距，必须小于它与下一组内容的间距。
- **对比要够**：浅底深字、深底浅字；主 CTA 实心强调色，次 CTA 线框或更小。
- **间距只走 4 / 8 刻度**：`4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48 / 64`。禁止 `7px`、`13px`、`15px`、`17px`、`25px`、`3.875rem` 等一次性值。
- **页边 padding ≥ 内部 gap**：`container-site` 水平内边距不得小于卡片网格 gap。推荐 `padding-inline: clamp(1.25rem, 4vw, 4rem)`，内部 gap `16--24px`。
- 圆角同样走 4 / 8：`8 / 12 / 16 / 999`（pill）。禁止 `17px` / `20px` / `25px` 作为站点默认（共享家具组件若写死，站点 CSS 覆盖回 8 刻度）。

### 4.2 首页结构（B2B 默认）

首页保持短路径，**不要**家具站「全家桶」。默认只保留：

1. Hero（一个焦点：身份 + 主 CTA）
2. 信任 / 指标
3. 产品
4. Why us（短）
5. **流程或证书条，二选一**
6. 最终 CTA

受众墙、房间墙、案例墙、生态四步、质保故事等，若与上列职责重复，删或并，不并排展览。

---

## 5. 图像与图标

- **统一照片调性**：同一站同一色温与对比；Chromora 用冷中性工业 / 纺织现场，禁止再引入家具客厅、成品椅、样板间。
- **图标只用线框（outline）**，描边色跟 Accent 或 Ink，禁止家具橙填充 `#c05c15` / `#C05C15`。
- 图必须服务文案：产品图对产品句，车间图对流程句。路径可沿用旧文件名，内容不得回退家具图。

---

## 6. CTA

- 每个视口 **一个主按钮**。主按钮（Get Quote / 获取报价）必须比次按钮（Request Sample / 申请样品）**更大、更实、更重**。
- 主：Accent 实心、`min-height: 56px`（`3.5rem`）、字重 600。
- 次：线框或浅边、`min-height: 40--44px`、字重 500、字号低一级。
- 禁止两个实心同色按钮并排。

## 7. Chromora 现状 → 目标

审计对象：`sites/chromora-yarns`（相对家具模板复制站）。

| 项 | 现状（审计） | 目标 |
|----|--------------|------|
| 首页密度 | Hero + 信任条 + 指标 + 生态四步 + Why us + 产品 + 受众六卡 + 流程 + CTA，家具叙事全家桶 | Hero → 指标 → 产品 → 短 Why us → 流程 → CTA。删除 assurance / ecosystem / audience |
| 配色 | `theme.json` 已是青绿，但站点 `@theme` 仍写家具橙与暖奶油；图标 SVG 填充 `#c05c15` | `@theme` 与 `theme.json` 同三色；图标线框青绿；页面上不可见 `#C05C15` |
| 字体 | `theme.json` 已是 Inter，CSS 仍声明 Poppins / Cinzel | CSS 变量与 `@import` 只留 Inter |
| 字号 | 导航 `15px`、下拉 `16px`、eyebrow `13px`、Hero `52px` | 4 级阶梯：12 / 16 / 24--32 / 32--48 |
| 间距 / 圆角 | 共享区块 `17px` / `20px` / `25px` 圆角；容器 `3.875rem` | 站点覆盖为 8 刻度；页边 ≥ 内 gap |
| CTA | Hero 主次同高同字号 | Get Quote 明显大于 Request Sample |
| 图像 | 分支已覆盖纱筒 / 纺织图 | 保持；禁止回退家具图 |
| Token 键 | 12 键与家具同名 | 保留键名以过校验；语义全部映射进三色 + 中性 |

家具站 `sites/ratahome-furniture` **不**套用 Chromora 三色与单字族；它仍可用橙 + Cinzel / Poppins，但新站默认按本文，不按家具站抄。

## 8. 验收清单

新站上线或改主题 / 首页前，下列全部勾选才算通过：

- [ ] 有彩色角色 ≤ 3，面积可指出 60-30-10
- [ ] 大面积只有中性色；Accent 只出现在 CTA / 链接 / eyebrow / 线框图标
- [ ] Chromora：强调色为 `rgb(14 92 99)`，表面为 `#F4F5F3` / 白，深色为 `#1C2224` 系
- [ ] 构建产物与站点 CSS 中无 `#C05C15` / `192 92 21` / Cinzel / Poppins（Chromora）
- [ ] 字族 ≤ 2（Chromora = 1，Inter）
- [ ] 可见字号只有 3--4 级，无 13 / 15 / 17 / 52 一次性值
- [ ] 中英文正文有 max-width，行宽落在 CN 25--40 / EN 45--75
- [ ] 间距与圆角走 4 / 8，页边 ≥ 内 gap
- [ ] 每区块一个焦点；首页不超过「Hero + 信任 + 产品 + Why us + 流程或证书 + CTA」
- [ ] 主 CTA 视觉权重大于次 CTA
- [ ] 照片调性统一；图标线框；无家具图回退
- [ ] 先删后加：能指出本轮删除的区块或 token，而不是只新增
- [ ] `ratahome-furniture` 构建与主题未被这次改动改坏
