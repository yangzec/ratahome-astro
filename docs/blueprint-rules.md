# 蓝图规则（强制）

## 分层

| 层 | 是什么 | 不是什么 |
| --- | --- | --- |
| **copy-final 蓝图**（`industry-*-blueprint.md`） | 买家可见定稿文案：导航标签、页脚、页面与各 section 的句子 | 指令、布局、CSS、栅格、断点、行话（如 fit the brief） |
| **站点 composition**（`sites/*/blueprints/*.json`） | 模板侧：首页 section **列表与顺序** | 文案蓝图；勿称 blueprint |
| **Section + design token** | 高度、栅格、比例、圆角、断点；按 `items.length` 自适应渲染 | 文案来源；不为凑版改 JSON 条数 |
| **brief / cross-compare / closure-status** | 给人看的建议、证据、缺口 | **不上站**，不写入 `sites/*/content/` |

蓝图条数不固定。模板只渲染且必须响应式：有几条画几格，禁止写死 N 列 / N 步，禁止为凑版生造或截断文案。0 条隐藏整段。栅格细则见 `docs/design.md`。

## 不为迁就模板而改蓝图

排版问题改模板，不改定稿句子。

**可以改蓝图的唯一理由**：文案本身很差——行话、指令腔、事实错误、不知所云、**同 section 主题拼盘 / 硬凑细项**。排版问题仍除外；除此之外不要动 copy-final。

**只改模板或 composition / token 的问题**：列数、Hero 高度、图比例、栅格、断点、区块顺序。这些不是「文案优化」。

**禁止**：

- 为凑 N 列删、补或截断卡片文案
- 为 Hero 好看砍标题或缩短主句
- 把排版 / 尺寸问题包装成「文案优化」再改蓝图或 content JSON

**默认顺序**：

1. 先让模板吃下现有文案：自适应列表、换 section、调 token。
2. 缺一类站都用得上的能力，再改共享模板。
3. 品牌皮肤只动 `theme.json`。

微调模板只允许沉淀通用能力；禁止为某一版蓝图开小灶（单站特例 composition 除外，且仍不得改蓝图句子来迁就版面）。

## 同一 section：单一主题（生成主规则，检查门禁）

一 H2 = 一买家问题 / 一主题；细项是同语义轴上的并列点，不是多个小章节硬塞一段。

**生成时处理顺序：**

1. 能同主题 → 保持，条数如实（有几条写几条）。
2. 明显两主题且好拆 → 拆成两个 section。
3. 难拆 → **上调 / 改写 H2 主题**，使标题与现有细项对齐（调主题 = 标题与内容对齐，≠ 把无关项美化塞进）。
4. 仍罩不住 → 删假点或整段不上首页；**宁少勿凑，禁止生造细项**。

**禁止硬凑：** 不为「满 N 卡」补空泛句；不为版面删真点；证据不足的主题可整段不上。

**与「不为迁就模板而改蓝图」的关系：**

- 因 **细项不同主题 / 拼盘 H2 / 假细项** 而拆段、调 H2、删假点 = **文案结构不合格**，在生成或检查回写时改蓝图 —— 这是文案质量，不是迁就版面。
- 因 **空一列、Hero 高度、图比例** 而改句子 / 补卡 / 砍标题 = **禁止**（只改模板）。
- 判断口诀：触发条件是「细项答的不是同一个买家问题」→ 可改蓝图；触发条件是「格子不够好看」→ 只改模板。

**检查门禁：** 套站前扫每段细项是否同主题；不合格回生成重写该段，禁止改模板凑版，禁止为版面删真卡。

## copy-final 蓝图 = 定稿文案

`industry-*-blueprint.md` 是**可直接上站的买家文案**：

- 导航、页脚、页面清单、各 section 的最终句子（买家口吻）
- EN（及需要的 ZH）正文可上线，不写「草稿」
- 不写「左栏 / 四列 / Hero 85vh」等排版说明

## 蓝图里禁止出现

- 指令腔：Share / 请发 / Please provide / as drawn / 报价路径（作内部词）…
- 执行备注：学 jd、可选、待补、勿照抄、← 注释、给 Agent 的说明
- 元评论：not a slogan wall、内部备忘口吻
- 设计圈行话：fit the brief、对得上简报，以及布局 / CSS / 列数
- 未核实的竞品自称数字（产能、客户名等）

## 建议 / 证据放哪

| 文件 | 角色 | 上站 |
| --- | --- | --- |
| brief | 给人看的一页建议 | 否 |
| cross-compare | 证据横比 | 否 |
| closure-status | 过程缺口 | 否 |
| **copy-final 蓝图** | **前台唯一文案源** | 是（写入 content JSON） |
| `sites/*/blueprints/*.json` | composition（区块顺序） | 是（模板配置，不是文案） |

套站时：只把 copy-final 蓝图写入 content JSON；不要把 brief/compare 里的「学谁」或布局说明写进前台。
