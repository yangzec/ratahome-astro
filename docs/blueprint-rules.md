# 蓝图规则（强制）

## 蓝图 = 定稿

`industry-*-blueprint.md`（及站点落地用的蓝图）是**可直接建站的定稿**：

- 导航、页脚、页面清单、各 section **最终文案**（买家口吻）
- EN（及需要的 ZH）正文可上线，不写「草稿」

## 蓝图里禁止出现

- 指令腔：Share / 请发 / Please provide / as drawn / 报价路径（作内部词）…
- 执行备注：学 jd、可选、待补、勿照抄、← 注释、给 Agent 的说明
- 元评论：not a slogan wall、内部备忘口吻
- 未核实的竞品自称数字（产能、客户名等）

## 建议 / 证据放哪

| 文件 | 角色 |
| --- | --- |
| brief | 给人看的一页建议 |
| cross-compare | 证据横比 |
| closure-status | 过程缺口 |
| **blueprint** | **定稿，上站唯一文案源** |

套站时：只把 blueprint 定稿写入 content JSON；不要把 brief/compare 里的「学谁」写进前台。
